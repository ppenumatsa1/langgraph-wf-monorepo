# Technology Stack

- Python 3.12, FastAPI, Uvicorn
- LangGraph with native PostgreSQL checkpointing
- Psycopg 3 connection pooling
- React, TypeScript, Vite, Nginx
- Azure Container Apps: external frontend and internal backend
- Azure Container Registry with managed-identity pull
- Azure Database for PostgreSQL Flexible Server
- Microsoft Foundry account/project and chat, embedding, evaluator deployments
- DefaultAzureCredential and least-privilege RBAC
- Log Analytics and Application Insights/OpenTelemetry
- Bicep at subscription scope and Azure Developer CLI
- Pytest, deterministic evals, Playwright, Docker Compose

Foundry is not the application host.
